One original one-line joke about crypto and trading life (max 200 characters), written for the make.fun bounty [Laugh Track: The Crypto Trading Joke Contest](https://make.fun/bounty/u-alfasurya91-laugh-track-the-crypto-trading-joke-a454158a). The entry program writes the joke as plain text to `/output/entry.txt`, where the house gate checks it (1–200 characters) and the judge model compares it two at a time against the other entries.

The joke (95 characters):

> The exchange went down for maintenance right as my coin pumped. It came back up when it dumped.

It was picked from 10 original candidates by a head-to-head judging pass against the contest brief — laugh, truth of trading life, economy of the line — using a free Groq model as the ammo judge.

## Run it

```sh
node main.ts
```

`main.ts` runs on Node 22.18 or later (Node runs its TypeScript as-is) and writes the joke to `/output/entry.txt` (override with `MAKEFUN_OUTPUT_DIR`). No dependencies, no network.
